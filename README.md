## Описание проекта
Кроссплатформенное приложение — сборник актуальных акций 
и скидок сетевых магазинов («Магнит», «Пятёрочка», «Лента», 
«Фикс Прайс», «Чижик», «Красное&Белое», «Доброцен»).

## Особенности
- Две версии: мобильное приложение и версия для компьютера
- Аккумуляция скидок из разных сетей в одном месте
- Фирменный стиль: чёрно-красная цветовая схема
